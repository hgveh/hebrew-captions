# כתוביות – עורך כתוביות בעברית

אפליקציית ווב (PWA) שרצה כולה בדפדפן: מעלים סרטון → תמלול אוטומטי לעברית → עיצוב ואנימציות → ייצוא לסטטוס וואטסאפ ושיתוף ישיר.

## הרצה במחשב
```
python -m http.server 8765
```
ואז לפתוח http://localhost:8765 ב-Chrome או Edge.

## שימוש בטלפון
צריך לארח את התיקייה באתר HTTPS (למשל GitHub Pages / Netlify / Cloudflare Pages – חינם).
פותחים ב-Chrome בטלפון → "הוסף למסך הבית". אחרי ההתקנה אפשר גם לשתף סרטון מהגלריה ישירות לאפליקציה.

## תמלול
⚙ הגדרות → בוחרים ספק ומדביקים מפתח API:
- **ElevenLabs Scribe** – הכי מדויק לעברית (מומלץ)
- **OpenAI Whisper**, **Groq** – חלופות
- **שרת משלך** – כל שרת תואם OpenAI, למשל מודל ivrit.ai

## מבנה
- `js/renderer.js` – ציור כתוביות ואנימציות (משותף לתצוגה ולייצוא)
- `js/transcribe.js` – חילוץ אודיו, ספקי תמלול, חלוקה לכתוביות
- `js/exporter.js` – קידוד MP4 (WebCodecs + mediabunny), חלוקה לחלקי סטטוס
- `js/app.js` – ממשק
